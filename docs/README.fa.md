# ENIGMA Student Planner — راهنمای فارسی

> برای توضیح فنی پروژه به [README انگلیسی](../README.md) مراجعه کنید.

برنامه‌ی مطالعه و گزارش پیشرفت دانش‌آموز کنکور — **یک فایل HTML، کاملاً آفلاین**.

بدون سرور، بدون نصب، بدون پایگاه‌داده، بدون اینترنت.
دانش‌آموز فقط فایل را در کروم باز می‌کند.

---

## فایل نهایی

```
dist/ENIGMA-Student-Planner.html      ← این را به دانش‌آموز بدهید
examples/ENIGMA-Week-03.json          ← نمونه‌ی فایل برنامه‌ی هفتگی
```

همه‌چیز (HTML + CSS + JavaScript + لوگو + برنامه + اطلاعات دانش‌آموز) داخل همان یک فایل است.

## برای دانش‌آموز

| کار | چطور |
|---|---|
| دیدن کارهای امروز | فایل را باز کن — صفحه‌ی **🏠 امروز** خودش می‌آید |
| تیک‌زدن یک کار | دکمه‌ی بزرگ **انجام شد** → چقدر زمان برد؟ چند تست زدی؟ → ذخیره |
| گرفتن برنامه‌ی جدید | منو ← **📥 وارد کردن برنامه جدید** ← فایل JSON مشاور را انتخاب کن |
| ذخیره‌ی کارها | منو ← **💾 ذخیره و دریافت فایل جدید** → فایل `ENIGMA-<نام>-Updated.html` |
| فرستادن گزارش | **📤 گزارش من** ← گزارش امروز یا گزارش این هفته ← چاپ/PDF یا ذخیره |

پنج بخش برنامه:

```
🏠 امروز        📅 برنامه هفته        📊 پیشرفت        📝 آزمون‌ها        📤 گزارش من
```

هر چیز دیگری (تنظیمات، حالت مشاور، پشتیبان‌گیری) پشت دکمه‌ی **منو** است.

> اطلاعات به‌صورت خودکار در حافظه‌ی همان مرورگر ذخیره می‌شود.
> برای انتقال بین دستگاه‌ها یا اطمینان بیشتر، از **💾 ذخیره و دریافت فایل جدید** استفاده کنید.

### دریافت برنامه روی گوشی

دکمه‌ی **📥 دریافت برنامه جدید** خودش یک `<label>` است که یک
`<input type="file">` نامرئی را کامل می‌پوشاند. یعنی با **یک لمس**، فایل‌منیجر
گوشی مستقیم باز می‌شود — بدون هیچ پنجره‌ی میانی و بدون `click()` برنامه‌نویسی‌شده
که مرورگر موبایل ممکن است آن را رد کند.

دانش‌آموز فایل را از Files / Downloads / تلگرام / واتس‌اپ انتخاب می‌کند،
پیش‌نمایش را می‌بیند، تأیید می‌کند و برنامه وارد می‌شود. بعد از آن، فایل JSON
دیگر لازم نیست.

### روی موبایل

برنامه برای گوشی ساخته شده، نه اینکه فقط نسخه‌ی کوچک‌شده‌ی دسکتاپ باشد:

- ناوبری پایین صفحه، همیشه در دسترس انگشت
- هر هفت روز هفته بدون اسکرول افقی در یک ردیف جا می‌شود
- پنجره‌ی «انجام شد» به‌صورت **شیت پایین صفحه** باز می‌شود و دکمه‌ی ذخیره تمام‌عرض زیر شست است
- همه‌ی دکمه‌ها دست‌کم ۴۴ پیکسل‌اند (روی هر دستگاه لمسی، حتی تبلت)
- اندازه‌ی فونت ورودی‌ها ۱۶px است تا سافاری آیفون موقع تایپ زوم نکند
- نمودارها اندازه‌ی خودشان را با عرض صفحه تنظیم می‌کنند و با چرخاندن گوشی دوباره رسم می‌شوند
- هیچ صفحه‌ای اسکرول افقی ندارد؛ جدول‌های عریض فقط داخل کادر خودشان اسکرول می‌شوند

آزمایش‌شده روی ۳۲۰ / ۳۷۵ / ۳۹۰ / ۴۳۰ و همچنین تبلت و دسکتاپ.

## برای مشاور

### ساخت برنامه‌ی هفته با فایل JSON

ساده‌ترین راه. یک فایل مثل `ENIGMA-Week-03.json` بسازید و برای دانش‌آموز بفرستید:

```json
{
  "enigma": "week-plan",
  "student": { "name": "امیر رضایی", "consultant": "آقای احمدی" },
  "week": {
    "title": "هفته ۳",
    "startDate": "۱۴۰۵/۰۶/۰۷",
    "note": "این هفته تمرکز روی مشتق است."
  },
  "days": [
    {
      "day": "شنبه",
      "note": "صبح با ریاضی شروع کن.",
      "tasks": [
        {
          "subject": "ریاضی",
          "topic": "مشتق",
          "title": "حل ۳۰ تست مشتق",
          "type": "تست",
          "minutes": 90,
          "questions": 30,
          "note": "زمان‌دار بزن."
        }
      ]
    }
  ]
}
```

قواعد فایل:

| کلید | توضیح |
|---|---|
| `week.startDate` | شمسی (`۱۴۰۵/۰۶/۰۷`) یا میلادی (`2026-08-29`) — خودش به شنبه گرد می‌شود |
| `day` | `شنبه` تا `جمعه` |
| `type` | `درس` · `تست` · `دوره` · `آزمونک` · `جمع‌بندی` · `تحلیل آزمون` · `سایر` |
| `minutes` | زمان برنامه‌ریزی‌شده به دقیقه |
| `questions` | تعداد تست هدف (اختیاری) |
| `note` | یادداشت مشاور که به دانش‌آموز نشان داده می‌شود |

دروسی که در فایل هستند و هنوز تعریف نشده‌اند، **خودکار ساخته می‌شوند**.
هفته‌ی جدید به برنامه **اضافه** می‌شود؛ هفته‌های قبلی پاک نمی‌شوند.
پس از وارد کردن، فایل JSON دیگر لازم نیست.

### ساخت برنامه داخل خود برنامه

منو ← **حالت مشاور**: ساخت هفته، افزودن/ویرایش/کپی/جابه‌جایی فعالیت، کپی هفته‌ی قبل،
الگو، تعریف آزمون، یادداشت و بازخورد، و خروجی HTML برای دانش‌آموز.

### دریافت عملکرد

دانش‌آموز فایل `ENIGMA-<نام>-Updated.html` را می‌فرستد — کافی است بازش کنید؛
همه‌چیز داخلش هست. برای ادغام در نسخه‌ی خودتان: تنظیمات ← **ورود عملکرد** (فایل JSON عملکرد).

## چرخه‌ی کاری

```
مشاور برنامه می‌سازد
        ↓  ENIGMA-Week-03.json
دانش‌آموز وارد می‌کند  →  در طول هفته تیک می‌زند
        ↓  ENIGMA-<نام>-Updated.html  +  گزارش هفتگی
مشاور بررسی می‌کند  →  هفته‌ی بعد را می‌سازد
```

## توسعه

```
src/
  index.html            نقطه‌ی شروع (مستقیم در مرورگر باز می‌شود، بدون سرور)
  assets/logo.js        لوگو به‌صورت data-URI
  css/
    tokens.css          متغیرهای طراحی (رنگ‌های لوگو: #0E1A32 / #2368E7 / #CEAD3A)
    base.css layout.css components.css views.css
    report.css          گزارش چاپی
    simple.css          لایه‌ی ساده‌سازی‌شده‌ی دانش‌آموز
  js/
    core.js             ابزارها، ثابت‌ها، قالب‌بندی اعداد فارسی
    date.js             تبدیل و نمایش تاریخ شمسی
    store.js            تنها منبع حقیقت (برنامه‌ی مشاور / عملکرد دانش‌آموز)
    stats.js            موتور محاسبات — همه‌ی اعداد از اینجا می‌آیند
    charts.js           نمودارهای SVG بدون کتابخانه
    ui.js               سازنده‌ی DOM، مودال، توست
    transfer.js         خروجی/ورودی HTML و JSON
    week-import.js      خواندن فایل برنامه‌ی هفتگی
    demo.js             داده‌ی نمونه
    app.js              پوسته، ناوبری، بوت
    views/              today · week · progress · exams · reports · consultant · settings · dashboard
build.js                ساخت فایل تک‌فایلی
tests/engine.test.js    ۲۵۷ تست موتور محاسبات
tools/serve.js          سرور محلی فقط برای تست
examples/               نمونه‌ی فایل برنامه‌ی هفتگی
reference/              PDF و لوگوی مرجع
```

ساخت و تست:

```bash
node build.js
```

```bash
node tests/engine.test.js
```

`src/index.html` را می‌توان مستقیماً هم باز کرد (اسکریپت‌ها کلاسیک‌اند، نه ماژول).
اما فایل قابل‌تحویل به دانش‌آموز همیشه `dist/ENIGMA-Student-Planner.html` است.

### قواعد معماری

- **برنامه‌ی مشاور** و **عملکرد دانش‌آموز** دو درخت جدا در state هستند.
- هیچ عددی ذخیره نمی‌شود؛ همه‌ی آمار و نمودارها از `stats.js` **مشتق** می‌شوند.
- زمان واقعی هرگز با زمان برنامه اشتباه نمی‌شود؛ اگر دانش‌آموز زمان ثبت نکند،
  از زمان برنامه استفاده می‌شود ولی همه‌جا با برچسب «تخمینی» نشان داده می‌شود.
- تاریخ‌ها میلادی (`YYYY-MM-DD`) ذخیره و شمسی نمایش داده می‌شوند.
- درصد آزمون با فرمول کنکور: `(۳×درست − غلط) ÷ (۳×کل) × ۱۰۰`.
